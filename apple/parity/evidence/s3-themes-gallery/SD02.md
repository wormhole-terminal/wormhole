## Clicks (`select_token`)

GPUI selects a token by click only on swatches: the terminal's 16 slots (`terminal.rs:83`) and the shape specimen's metric
boxes (`shape.rs:122`). No marked element takes a click (an element is drawn with many tokens, there is none to pick), so the
task's "click on any labelled element" is not GPUI behaviour; the two real cases are:

- [x] Terminal swatches select their token (already in Swift; unchanged).
- [x] Metric boxes select `metrics.radius_sm|radius_chip|radius|radius_lg|focus_ring_width`, ringed in the primary while
  selected, the key bold: new in `ShapeSpecimen.swift`. Run: `click 596 711` on `radius_lg` selected `metrics.radius_lg`
  (`sd02-shape-before-click.png`, `sd02-shape-after-click.png`). A unit test cannot do it (a button in a window that was never
  ordered in takes no event), so the click is the instance's.
