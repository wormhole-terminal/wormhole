# Agent logos

Monochrome logos shown next to terminals in the sidebar and in Settings → Coding
agents. They are drawn tinted with the theme's text color.

All files come unmodified (only renamed) from [Simple Icons](https://simpleicons.org)
v16.33.0 (`https://cdn.jsdelivr.net/npm/simple-icons@16.33.0/icons/<slug>.svg`).
Simple Icons releases its SVGs under [CC0 1.0](https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md);
where an icon lists its own license, that one applies instead. The logos are
trademarks of their owners, used only to name the product they stand for —
no affiliation or endorsement is implied (see Simple Icons'
[disclaimer](https://github.com/simple-icons/simple-icons/blob/develop/DISCLAIMER.md)).
